# Sudhev Mathew Abi — Personal Portfolio

Dark red/black developer portfolio built with Next.js.

## Run locally

```bash
cd portfolio
npm install
npm run dev -- -p 3001
```

Or from the repo root:

```bash
npm run dev:portfolio
```

Open [http://localhost:3001](http://localhost:3001).

## Customize

Edit `src/data/site.ts` for name, bio, projects, skills, and contact links.
Replace images under `public/images/`.
